# MonitorMouse

外部モニター接続時など、**ウィンドウを別モニターへ切り替えると、その切り替え先モニターの中心へマウスカーソルを自動移動**する Windows 常駐ツール。

Alt+Tab / Ctrl+Tab(別ウィンドウへの切替) など、別モニターのウィンドウへ切り替えたときに動作します。
カーソルが既に切替先と同じモニター上にあるとき・クリックでフォーカスしたとき・
スリープ/ロックからの復帰直後は移動しません(勝手に飛ばない)。
追加インストール不要（Windows PowerShell + .NET Framework のみ使用）。

## 動作仕様

- **外部モニター接続時（画面が2台以上）のみ動作します。** 単一画面のときは何もしません（実質オフ）。
  接続／切断は切り替えごとに毎回判定するため、デーモンを再起動しなくても即座に反映されます。
- 最前面ウィンドウが**別のモニターへ**変わったとき、そのウィンドウが乗っているモニターの
  **中心へ**カーソルを移動。本体画面・外部モニターを問わず、どのモニターへ切り替えても追従します。
- **カーソルが既に切替先ウィンドウと同じモニター上にあるときは移動しません。**
  これにより、タスクバーの「隠れているインジケーターを表示します」やトレイのミニアプリ
  (monitorian 等)のフライアウトを開いても、カーソルが中央へ飛びません。
- **マウスボタンを押している間（＝クリックでフォーカスした場合）は移動しません**。
  これにより Alt+Tab / Ctrl+Tab 等のキーボード切替では確実に中心へ移動し、
  クリック操作では勝手にカーソルが飛ばないようにしています。
- **スリープ／画面ロックからの復帰直後（既定 3 秒間）は移動しません。**
  復帰時のディスプレイ再構成・前面ウィンドウ復元で発生するイベントによって
  カーソルが勝手に中央へ飛ぶのを防ぎます（セッションのロック/アンロックと
  サスペンド/復帰の通知を受け取って判定します）。
- **スクリーンショットツール（Snipping Tool 等）のウィンドウが前面のときは移動しません。**
  Snipping Tool のキャプチャオーバーレイはメインモニターに前面表示されるため、これを除外しないと
  サブモニター上の範囲選択がメイン画面へ引き戻されてしまいます。前面ウィンドウの所属プロセス名で
  判定するので、ショートカット（Win+Shift+S など）や起動方法に依存しません。

### 注意点
- **Ctrl+Tab が「同一ウィンドウ内のタブ切り替え」の場合は発火しません。**
  最前面ウィンドウ自体が変わらないためです。別ウィンドウ／別アプリへの切り替えなら動作します。
- **管理者権限で動いているアプリ**へ／から切り替える場合、本ツールが管理者権限で
  動いていないと Windows の UIPI により切替イベントを受け取れず、移動しないことがあります。
  その場合はツール自体を管理者として実行してください。
- 複数DPI(拡大率が混在)環境では、Per-Monitor DPI 対応を起動時に設定して座標ずれを抑えています。

## 使い方

### 動作確認（前面・コンソール表示）
```
test.bat
```
をダブルクリック。別モニターのウィンドウへ Alt+Tab して、カーソルが中心へ飛べばOK。停止は `Ctrl+C`。

### 自動起動の登録（常駐）
PowerShell で:
```
powershell -ExecutionPolicy Bypass -File install.ps1
```
- スタートアップに登録され、次回ログイン以降は自動で常駐します（コンソール窓は出ません）。
- 実行と同時に常駐も開始します。

### 解除・停止
```
powershell -ExecutionPolicy Bypass -File uninstall.ps1
```
自動起動の登録解除と、動作中インスタンスの停止を行います。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `MonitorMouse.ps1` | 本体（フック＋カーソル移動の常駐デーモン） |
| `launch-hidden.vbs` | コンソール窓を出さずに本体を起動するランチャー |
| `install.ps1` | 自動起動登録＋即時起動 |
| `uninstall.ps1` | 自動起動解除＋停止 |
| `test.bat` | 動作確認用（前面実行） |

## カスタマイズ
`MonitorMouse.ps1` の C# 内 `OnForeground` を編集します。

- **どのモニターでも追従せず外部モニターのみにしたい**場合:
  `GetMonitorInfo` 取得後に `(mi.dwFlags & 0x1) != 0`（MONITORINFOF_PRIMARY＝本体画面）なら `return;` する。
- **モニター中心ではなく作業領域(タスクバー除く)の中心**にしたい場合:
  `mi.rcMonitor` を `mi.rcWork` に置き換える。
- **クリックでフォーカスした場合も中心へ寄せたい**場合:
  `GetAsyncKeyState(...)` による3つのスキップ判定を削除する。
- **同じモニター内の切替でも毎回中心へ寄せたい**場合（既定では同一モニター内では動かない）:
  `OnSettle` 内の `GetCursorPos`/`MonitorFromPoint` による同一モニター判定の行を削除する。
- **スリープ/ロック復帰後の抑制時間を変えたい**場合:
  `RESUME_GRACE_MS`（ミリ秒）の値を調整する。
- **スクショツールを追加・変更したい**場合（既定は Windows の Snipping Tool）:
  `SCREENSHOT_PROCS` 配列に対象の実行ファイル名を追加する（例: `ShareX.exe`、`Greenshot.exe`、
  `Lightshot.exe` など）。前面ウィンドウの所属プロセス名と大文字小文字を無視して照合し、
  一致すれば `OnSettle` でカーソルを動かさない。`.exe` を含めて記述する。
